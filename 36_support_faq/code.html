🔒 봉인 흑역사 봉인 시스템은 정확히 어떻게 작동하나요?
△

흑역사 봉인 시스템은 3단계로 작동합니다:

  1. 회원가입 또는 마이페이지에서 흑역사 콘텐츠(사진·영상·반성문·음성)를 봉인소에 업로드
  2. 학습 목표를 설정하고 공개 트리거(주간 학습 시간·연속 출석·시험 D-day 등) 조건 선택
  3. 학습 목표 미달성 시 안전 모니터링을 거쳐 설정된 공개 대상(SNS·지인)에게 자동 공개

봉인 콘텐츠는 학습 성공 시 안전하게 보관되며, 24시간 후 자동 삭제됩니다.

🔒 봉인 봉인된 흑역사가 공개되는 정확한 조건은 무엇인가요?
△

공개 트리거는 봉인 시 사용자가 직접 선택합니다:

  • 주간 학습 목표 미달성 (예: 20시간/주)
  • 연속 출석 끊김 (예: 3일 이상)
  • 시험 D-day 누적 학습 시간 부족
  • 월 누적 학습 시간 부족

각 트리거의 위험도 기여도는 패널티 위험도(P-FE-MY-10) 화면에서 실시간 확인 가능합니다. 위험도가 100%에 도달하면 다음 검증 시점에 자동 공개됩니다.
