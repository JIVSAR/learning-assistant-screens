SQL JOIN 종류에 대해서 쉽게 설명해줘. INNER, LEFT, RIGHT, FULL 비교줘.
🤖
네, SQL JOIN에 대해 쉽게 설명해드릴게요. JOIN은 두 개 이상의 테이블을 연결하여 데이터를 함께 보는 연산입니다.
1. INNER JOIN (교집합) — 두 테이블에 모두 있는 데이터만 가져옴
2. LEFT JOIN — 왼쪽 테이블의 모든 데이터 + 오른쪽 매칭
3. RIGHT JOIN — 오른쪽 테이블 모두 + 왼쪽 매칭
4. FULL OUTER JOIN — 두 테이블의 데이터를 모두 가져옴
SELECT *
FROM TableA
INNER JOIN TableB ON A.id = B.id;
